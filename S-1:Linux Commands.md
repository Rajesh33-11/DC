
*** Linux Commands (S1)

 
 

 
 
•	Shell -  A shell is like a messenger between you and Linux.
You type commands → the shell understands them → the shell tells the system what to do.
•	Hardware: Hardware means the physical parts of a computer — the things you can touch. Hardware is all the physical components that make a computer work.
•	Kernel: The kernel is the core (center) of an operating system like Linux.  The kernel is the main part of the OS that connects software to hardware.
It’s like the boss that controls everything happening inside the computer.
•	Appliaction: Application is nothing but the place wherever applications are Present.

 

•	ls -  Show Short Lists files
  Syntax : ls
 
•	ll -  Show Long Lists files
  Syntax : ll
 
•	touch -  Creates file
  Syntax : touch filename
 


•	touch -  Creates file
  Syntax : touch filename  filename   filename
 
•	touch filename{1..10} -  create series of  files
  Syntax : touch raja{1..10}
 
•	rm filename -  remove files. 
  Syntax : rmdir raja5
 


•	rm filename filename -  remove multiple  directories. 
  Syntax : rmdir filename filename
 
•	rm filename* -  remove series of  files
  Syntax : rm filename_startletter*
 
•	rm –rf *-  remove all files and directories
  Syntax : rm –rf*
